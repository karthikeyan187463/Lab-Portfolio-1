# *Lab Portfolio-1*
# AWS Cloud Formation
  A small company FridayHITT provide customised different HITT training every Friday with running
routes local to the location. They have approached to design a mini network for the online
presence. They can see that the company will expand rapidly so they want the design to be extensible
from the start. 

This Repository mainly consists of YAML files where the project is based on the *CloudFormation Stack* using the application composer.
Based on the requirements of the design for the stack the script have been structured.
The progress which have been completed is given as YAML files *day by day*.
